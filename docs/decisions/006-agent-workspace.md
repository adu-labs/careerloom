# ADR-006：记录驱动的 AI 工作台与可复用运行层

## 状态

Proposed — 用户已提出记录、会话主入口、Agent harness与后台持续优化的产品要求；以下为本轮技术设计，尚未实施。补充 ADR-004，不替代其持久工作流原则。

## 日期

2026-09-16

## 背景

用户平时工作和学习材料易散失；生成简历需要完整读取自选记录、维护事实来源、多轮修订并交付可持续编辑的产物。未来其他产品也需要复用任务与评测能力。

## 决策建议

以轻量版本化记录为材料，以 AI 会话为求职者默认入口，同时保留直接编辑与传统视图。选定来源逐块建立覆盖清单，事实候选与产物引用来源。复用当前任务底座，将运行、工具、产物、观测和评测协议分层；先在简历与面试复盘两场景验证，之后提取独立包。

观测从首个真实任务接入；业务事件、诊断、审计与授权样本分流。模型/提示/工具/工作流版本可追溯，改进经评测与灰度，不直接以原始用户对话自动训练或自动发布。

## 备选与权衡

全部改成纯聊天会使版本、批量选择和精细排版更费力；只加聊天按钮不能解决产物和任务恢复。所有笔记塞进单次提示会受到容量、权限和遗漏影响；仅检索 top-k 不满足全部读取。立即建设通用 Agent SaaS 会把资源投入尚未证明需要的抽象。

## 影响

新增材料覆盖、事实来源和反馈治理成本；可换取更可解释的结果和可复现的问题。任务完成与用户觉得有用分别度量，接受率不能证明事实正确。可复用的是代码与质量方法，私人材料不跨产品共享。
