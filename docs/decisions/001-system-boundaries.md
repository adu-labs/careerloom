# ADR-001：模块化后端与隔离任务运行时

## 状态

Proposed — 本轮技术建议，尚未实施；明确产品约束来自用户，具体技术选择待风险验证后确认。

## 日期

2026-09-16

## 背景

平台横跨身份、招聘、简历、内容、交易；早期独立微服务会增加分布式事务成本。用户源码编译和实时语音又有不同的安全与运行要求。

## 决策建议

Web 采用 Next.js，业务 API 采用 NestJS 模块化单体；PostgreSQL 是业务真源。排版、AI、索引与语音独立进程／部署单元。REST + OpenAPI 共享契约。队列由 outbox 驱动，任务状态持久化。

## 备选与权衡

全部逻辑放页面服务：起步方便，但编译、长会话与交易边界容易混杂。每模块一个微服务：可独立扩容，但当前团队规模和负载未证实需要。继续扩展静态原型：不能提供生产鉴权与一致性。

## 影响

需维护少量基础组件与部署流程；换前端不重写业务。供应商、框架版本和容量需实测锁定。只有隔离或负载需要时再拆服务。
