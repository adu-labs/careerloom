# ADR-005：订单权益、返现与服务商结算分账

## 状态

Proposed — 本轮技术建议，尚未实施；明确产品约束来自用户，具体技术选择待风险验证后确认。

## 日期

2026-09-16

## 背景

用户计划通过模板、内推合作、猎头和人工服务收费，并给服务使用者返现。截图不能直接证明可扣服务商的金额，重复通知可能重复授予权益。

## 决策建议

订单、支付事件、使用权益、返现申请、服务商应收和追加账务分别建模。服务器验签核价、幂等入账；退款做冲正。人工服务先建订单归因；返现审核与佣金确认独立；线下合作结果通过管理端核销。

## 备选与权衡

只靠用户截图计佣：易漏报或争议。支付成功页直接发权益：容易伪造。只保存可修改余额：无法解释退款和核销。强制所有服务方完整注册：增加对接负担且不符合现阶段运营方式。

## 影响

需要人工对账、争议处理与审计，但可清楚解释资金来源。10 元返现是一种反馈激励，不能保证全部成交被捕获。
