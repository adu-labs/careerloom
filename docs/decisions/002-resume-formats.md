# ADR-002：结构化内容与四格式并行支持

## 状态

Proposed — 本轮技术建议，尚未实施；明确产品约束来自用户，具体技术选择待风险验证后确认。

## 日期

2026-09-16

## 背景

用户明确要求 JSON、YAML、LaTeX，并希望支持有生态价值的 Typst。格式语法、简历方言、排版程序与模板不能混为一谈，任意源码无法可靠还原成表单。

## 决策建议

平台内容 schema 与模板 manifest 版本化。JSON/YAML 为原生交换表达；JSON Resume 和 RenderCV 用适配器。LaTeX/Typst 保留源码工程、隔离编译和导出；声明数据接口的模板额外支持可视化编辑。默认原生输出选 Typst，中文排版试验为采用门槛。

## 备选与权衡

只支持 LaTeX：难以服务普通表单编辑用户。只用私有 JSON：阻碍用户自带模板。全部自动无损转换：对任意宏与布局不成立。仅上传源码：不能满足本次支持要求。

## 影响

需要维护多个 adapter 和编译镜像；必须公布兼容范围。受支持字段可保语义往返，未知结构原样保留并报告。模板、依赖和字体都固定版本。
