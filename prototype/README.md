面向中国互联网/技术类实习、校招和社招的交互原型。

## 本地预览

在 dist 目录运行 `python3 -m http.server 4173`，打开 http://localhost:4173。无构建依赖。

也可从仓库根目录运行 `python3 -m http.server 8080 --bind 127.0.0.1 --directory prototype/dist`，打开 http://127.0.0.1:8080。已有本机资料会保留；首次入口可以在隐私窗口查看。

`style.css` 提供基础组件，`workspace-ui.css` 提供统一主题与响应式布局，`workspace-ui.js` 组织首次入口与今日工作台。主题不改变用户自定义简历的排版；不依赖远程图片或字体。

## 范围

包含三种求职入口、今日工作台、简历编辑与版本管理、岗位与内推、投递管理、面试练习、简历市场、人工服务、社招猎头，以及服务方/平台负责人演示视角。

数据均为虚构示例，仅在浏览器 localStorage 保存。角色切换不是权限认证。购买、服务订单、佣金、返现、猎头核验和 AI 反馈均为流程模拟，不发生真实交易或发送信息。

## 本机数据保护与回归

Q01 新增 `storage.js` 作为存储读取边界。有效旧数据保持原键与字段；空简历库仍可刷新和新建。JSON 无法解析或集合结构损坏时暂停写入，并提供原始数据备份、确认重置入口，不自动用样例覆盖。模板名称按文本显示；文件选择仅接受最后一次有效读取结果。详见 [Q01 审阅记录](../docs/implementation-review/Q01-prototype-reliability.md)，当前待用户审阅。

可执行 `npm run test:prototype`（不监听端口）和 `npm run check:prototype`；浏览器布局仍需单独验证。

## 第二轮迭代

加入猎头与企业 HR 独立入口、受托岗位/企业岗位发布审核、私人机会、用户待办、可切换周日历、模板与任意简历导入、回收站、英文草稿确认、分别授权 HR/猎头的展示快照。

面试模块新增日程、自动/自定义题单、问答聊天、暂停恢复和自动归档；独立复盘库支持 Markdown 编辑预览、全文检索、示例 AI 建议与导出；面经社区支持独立草稿、审核和组卷许可。

麦克风只由用户主动开启；SpeechRecognition 取决于浏览器及识别服务，拒绝授权或不支持时可继续文字输入。未接入真实 LLM，题库与反馈为规则示例。英文转换仅内置样例文本，自定义中文会明确标记待译。

角色权限属于产品演示，并非安全边界；正式实现需要后端记录级授权。站外对接、服务单限时链接、认证、真实社区与交易尚未接入。

本轮验证：待办创建/完成、日历日期切换、内推返回、定向创建取消、任意简历导入/回收恢复、自定义面试问答与自动复盘、全文检索/建议插入/面经待审核、HR 发布→管理员审核→普通用户检索、官网链接、390px 移动端宽度。没有自动开启麦克风录入用户音频。
