# Contributions and permissions

Careerloom is publicly viewable but is not open-source software. Read [LICENSE](LICENSE) before using repository materials.

We currently welcome issue reports and product feedback. Do not include personal resumes, work records, credentials, confidential information, or third-party code in public issues.

External code and documentation contributions are not currently solicited. Before preparing a patch, contact the maintainer to agree in writing on the contribution's scope and the rights necessary for the project to use it. Opening a pull request does not assign copyright or automatically establish a contributor licensing agreement.

Repository access, contributor status, and author attribution do not independently grant rights to redistribute or deploy project materials. Authorized maintainers operate under their applicable rights and permissions.
